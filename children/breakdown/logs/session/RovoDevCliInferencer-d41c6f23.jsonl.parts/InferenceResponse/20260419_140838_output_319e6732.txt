
```bash
twg jira workitem create --space PROJ --type Task --summary "New task" 
--assignee me
```

Update an issue:

```bash
twg jira workitem update --id PROJ-123 --summary "Updated title" --assignee me
```

Transition an issue (change status):

```bash
twg jira workitem transition --id PROJ-123 --transition-id 21
```

```bash
twg jira space status list --id-or-key PROJ
```

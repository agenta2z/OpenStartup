==============================================================
Proactive AI Platform — Codebase Understanding Documentation
==============================================================

:Date: 2026-05-05
:Scope: ``proactive-ai-platform`` (118 source files, ~7,765 LoC) +
        32 test files (~6,313 LoC)

Comprehensive documentation for the ``proactive-ai-platform`` codebase — Atlassian's
**Spring Boot Kotlin micros service** that backs the *proactive AI experiences* layer
across Jira, Confluence, and Rovo (proactive nudges, conversation starters, Rovo Insights).

This documentation set was generated by multi-agent parallel investigation
of the live source tree plus Bitbucket PR reads (#96 – #108).
Every numerical claim is cross-verified against ``find + wc -l`` output.

Verified scope (2026-05-05)
=============================

* **118 main Kotlin files** (~7,765 LoC) across 16 top-level packages under ``io.atlassian.micros.proactiveai``
* **32 test files** (~6,313 LoC) — 0.81× test/main LoC ratio
* **3 feature packages**: rovoinsights (16 files, 658 LoC), nudge (4 files, 72 LoC), greeting (1 file, 56 LoC)
* **12 platform packages**: requestcontext (14/906), service/metric (5/1243), featuregate (8/754), task (11/649), stratus (8/587), logging (6/568), utility (8/557), client (7/399), context (9/381), sqs (8/302), interceptor (5/295), config (6/208), exception (1/116)
* **6+ external integrations**: AI Gateway, IdGatekeeper, Statsig, AWS SQS, StreamHub, SignalFx, Redis (Valkey 7.x)
* **Deployment**: Atlassian Micros (Spring Boot 7.10), 2 worker groups (``SHWorkers``, ``LongRun``)

How to read this documentation
================================

* **Brand new to PAI?** Start with :doc:`overviews/02-architectural-narrative` (a walking tour from HTTP request to SQS-driven worker).
* **Need the cross-package picture?** :doc:`overviews/01-multi-axis-matrix` has size × tier × purpose tables for all 16 packages.
* **SRE / on-call?** :doc:`overviews/03-criticality-dashboard` ranks packages by blast-radius.
* **What is this team building this year?** :doc:`architecture/cross-cutting/01-business-and-technical-goals` covers the FY26 H2 OKR (400K → 1.5M monthly AI invocations).
* **What did this codebase look like 6 months ago?** :doc:`architecture/cross-cutting/02-development-history` walks the strategic PRs (#96–#108) chronologically.
* **Architecture deep dive?** :doc:`architecture/index` covers request lifecycle, AI Gateway, async tasks, feature flags, auth.
* **Per-feature detail?** :doc:`modules/features/index` has deep-dives for ``rovoinsights``, ``nudge``, ``greeting``.
* **Per-platform-layer detail?** :doc:`modules/platform/index` has deep-dives for all 12 cross-cutting layers.
* **Opening a PR — what tests/lint/CI checks must pass?** Read ``TESTING_SOP.md`` (canonical Markdown — not yet wired into Sphinx toctree). Covers all 5 PR blocking checks, the 3 test categories (``*Test`` / ``*IT`` / ``*AcceptanceTest``), unit-test conventions (MockK + WireMock + JUnit5), and 14 verified policy gaps.

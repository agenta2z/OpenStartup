# Renovate

Every time a new version of one of your dependencies is released, [Renovate](https://go/renovate) will automatically raise a PR against your repository that upgrades the version. You can then review the PRs and merge them to always stay up-to-date.

To onboard your repository to Renovate, please follow the [Getting Started](https://hello.atlassian.net/wiki/spaces/MOBUILD/pages/532708641/Renovate+-+Getting+Started) docs.

The file `renovate.json5` provides an example configuration for Renovate.

==================================
Glossary
==================================

Cross-cutting acronyms and terms used throughout the ``gcp_kitt`` repo
and this documentation set.

.. glossary::

   AMP
       Atlas Micros Platform — historical name for the Atlassian internal
       compute platform. The ``amp/`` directory hosts the **Distributed
       Task Execution (DTE)** Go control-plane that originally lived as a
       Node.js spike in ``amp-spike/``.

   ASAP
       *Atlassian Service Authentication Protocol* — JWT-style service-to-
       service auth token issued by ``atlas slauth``. Carried as
       ``X-DTE-ASAP`` to ``distributed-client``.

   ASI
       *Atlassian Service Infrastructure* — the cluster-scoped CRD
       (``asis.platform.atlassian.com/v1``) reconciled by the operator at
       ``asi/``. Each ``ASI`` resource binds a K8s ServiceAccount to a GCP
       IAM service account via Workload Identity.

   Argo Workflows
       The Kubernetes-native workflow CRD that the DTE worker bridges to
       inside each remote cluster. Workflow YAMLs are generated by
       ``createServiceDiscoveryWorkflowYAML`` and
       ``createHealthCheckWorkflowYAML`` in
       ``amp/distributed-worker/main.go`` and posted via
       ``createWorkflowViaAPI`` (``helpers.go``).

   AsyncTask
       (PAI-specific term, not used in KITT — listed only for cross-doc
       comparison.) See ``proactive-ai-platform`` for that pattern.

   Auth Provider
       Per-cluster HTTP service that exchanges an operator's
       ASAP+SCT (or SLAuth) token for a short-lived bearer token bound to
       the operator's filtered ``kube-*`` AD groups. Called from
       ``getClusterTokenFromAuthProvider`` in
       ``amp/distributed-worker/helpers.go``. Documented in
       ``dte-web/auth-provider.md``.

   Centrify
       Atlassian-internal directory used to issue mTLS certs (``CENTRIFY_CERT``
       / ``CENTRIFY_KEY`` environment vars referenced in ``dte-web/README.md``).

   Cluster Registry
       The S3 bucket ``kitt-cluster-registry.s3.amazonaws.com`` whose
       ``/latest/apis/clusterregistry.k8s.io/v1alpha1/...`` JSON describes
       every member cluster. Read by ``cluster_db.go``. AWS Signature V4
       is required (no SLAuth).

   ClusterInfo
       Go struct in ``amp/distributed-worker/cluster_db.go`` and
       ``helmfile/dte/pkg/cluster/cluster_db.go`` containing master
       endpoint, CA cert, auth-provider URL, and metadata.

   CRD
       *CustomResourceDefinition*. KITT defines two cluster-scoped CRDs in
       this repo: ``asis.platform.atlassian.com/v1`` and
       ``sweepers.platform.atlassian.com/v1``.

   Cyclops
       Open-source Atlassian-Labs node-cycling controller. The
       ``WorkflowCyclopsCycleNodes`` runbook in ``kitt-runbooks/`` builds
       ``CycleNodeRequest`` resources in ``kube-system``.

   DTE
       *Distributed Task Execution* — the Go + Temporal control plane that
       fans out a single operator command to multiple member clusters in
       parallel. Two operative components: ``distributed-client``
       (HTTP API) and ``distributed-worker`` (Temporal worker).

   DTE Web
       Express.js + static SPA in ``dte-web/`` providing a browser UI on
       top of ``distributed-client`` and ``temporal-web``.

   dtecli
       Atlas-plugin Node.js CLI in ``dtecli/`` exposing five command groups
       (``auth``, ``cluster``, ``config``, ``runner``, ``workflow``).

   ESDK
       *AWS Encryption SDK* — used in
       ``portable-cryptor/kms_encrypt_decrypt_esdk.py`` for envelope
       encryption when wrapping RSA-2048 private keys for portable import
       between clouds.

   Filebeat-DTE
       The Helm chart at ``logging/charts/fluent-bit-dte`` (note:
       Fluent-Bit despite the directory naming containing ``filebeat`` in
       sibling scripts). Ships container logs to Elasticsearch via the
       ingest pipelines defined in ``elasticsearch-ingest-pipeline.json``.

   Forge
       Atlassian's app platform; ``forge_containers/`` contains the
       runtime-container fleet plus a custom ``helm-crd`` controller and
       ``forgeapp-deployment.ts``.

   GitOps
       The deployment model implemented via ``argocd/``: ArgoCD watches
       ``argocd/cluster-apps/`` and applies the rendered helmfile output.

   Helmfile
       Wrapper around ``helm`` that renders multiple charts as a single
       unit. ``helmfile/helmfile.yaml`` is the top-level orchestrator;
       per-component subdirectories carry their own helmfiles.

   IAM-Sidecar
       Go HTTP sidecar in ``iam-sidecar/`` that exposes ``/token`` on
       localhost and mints GCP access/ID tokens via
       ``iamcredentials.GenerateAccessToken/GenerateIdToken``.

   Istio / Kourier
       Service-mesh and Knative-ingress combo deployed by the helmfile
       chain. Step 8–9 of ``DEPLOYMENT_ORDER.md``.

   KEDA
       Kubernetes Event-Driven Autoscaler. Used to scale Temporal workers
       (``scraper/temporal-pg-redis/scale-workers.sh``,
       ``debug-keda-scaling.sh``). Grafana dashboard:
       ``monitoring/grafana-keda-scaledobjects.json``.

   KITT
       *Kubernetes Infrastructure Tooling* — the umbrella name for
       Atlassian's internal multi-cluster Kubernetes platform. This repo
       is its **GCP** leg.

   Knative
       Serverless layer for K8s used to host ``distributed-client``,
       ``distributed-worker``, ``dte-web``, and ``dtecli/bootstrap``
       (``js-worker-knative-service.yaml``).

   Kueue
       Job-queueing system used by ``pae/`` and ``pae-apps/``. CRDs
       documented in ``KUEUE-CRDS.md``.

   MICROS_GROUP
       (PAI-specific env var, NOT used in KITT.) Listed for cross-doc
       comparison only.

   Member cluster
       Any GKE cluster registered in the cluster registry that
       ``distributed-worker`` activities can target.

   Rollcall
       Atlassian-internal API exposing AD-group membership; queried by
       ``dtecli/src/lib/ad-groups.ts`` and shown in the
       ``dte-web/README.md`` curl example. Used to populate
       ``X-DTE-GROUPS``.

   Runbook
       A Temporal workflow under ``kitt-runbooks/`` that automates a
       previously-manual SRE procedure (cordoned node, node cycle,
       unhealthy deployments).

   Sauron
       (Not used in KITT — PAI-specific. Listed for cross-doc clarity.)

   SCT
       *Service Context Token* — second half of the modern dual-token auth
       (alongside ASAP). Carried as ``X-DTE-SCT``. ``isSCTToken`` in
       ``helpers.go`` distinguishes it.

   Service Discovery
       DTE task type that enumerates services per cluster.
       ``createServiceDiscoveryWorkflowYAML`` produces the Argo workflow
       YAML; ``FilterServiceDiscoveryResultsActivity`` post-processes the
       output before returning to the client.

   SLAuth
       *Service-Level Authentication* — Atlassian internal SLAuth tokens.
       Legacy single-token mode (``X-DTE-Auth-Token`` header on
       ``distributed-client``) is mutually exclusive with the modern
       ASAP+SCT pair.

   Splunk
       Log search platform queried by
       ``kitt-runbooks/internal/splunk/client.go`` from the
       ``CheckLogsForCordonAuditActivity``.

   Sweeper
       The CRD (``sweepers.platform.atlassian.com/v1``) and operator that
       periodically labels pods with metadata such as ``serviceID``.

   TaskQueue ``dte-workflows``
       The Temporal task queue on which ``distributed-client`` enqueues
       ``DistributedTaskExecutionWorkflow`` and that
       ``distributed-worker`` polls. Hardcoded in
       ``amp/distributed-client/main.go`` (lines 920, 1044 per
       ``INTEGRATION_REVIEW.md``); the worker reads ``TEMPORAL_TASKQUEUE``
       env var (default ``dte-workflows``).

   TaskQueue ``kitt-runbooks``
       The Temporal task queue polled by the runbook worker
       (``kitt-runbooks/cmd/worker/main.go``).

   tctl
       The Temporal CLI; many helmfile scripts run it via the
       ``temporal-tools`` image (``docker.atl-paas.net/kitt/temporal-tools:1.0.1``).

   Volcano
       GPU/batch scheduler deployed by ``vocalno/``.

   Workload Identity
       GCP feature that allows a K8s ServiceAccount to impersonate a GCP
       IAM service account. Configured by the ASI operator's
       ``bindIAMRole``.

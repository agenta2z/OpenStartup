Per-module catalog¶

This section catalogs every directory under atlassian_packages/gcp_kitt/ with deep-dive content. Each module document follows a consistent shape:

  • Purpose — one-paragraph statement of intent

  • Tech stack — languages, frameworks, key dependencies

  • Inventory — file count, key files with role/LoC

  • Public surface — CRDs, HTTP endpoints, CLI commands, Temporal workflows

  • Auth & RBAC — SLAuth, ASAP, JWT, GCP IAM, K8s ClusterRoles

  • Build & deploy — Make targets, helmfile commands, scripts

  • Integration — how it wires into the rest of the platform

  • Hazards — production gotchas observed from docs/code

The grouping below mirrors the Walking Tour in Architectural narrative — a walking tour.

Distributed Task Execution (DTE)¶

  • amp/ — DTE distributed client & worker (Go)
  • amp-spike/ — earliest DTE prototype (Express.js)
  • dtecli/ — DTE TypeScript CLI + Temporal-Cloud bootstrap
  • dte-web/ — DTE Web UI + REST proxy (Express.js)

Helm-deployed platform¶

  • helmfile/ — the Helm-based platform (largest subsystem)
  • deploy/ — secondary helmfile + sample / test workloads
  • argocd/ — GitOps app-of-apps

Kubernetes operators¶

  • asi/ — Atlassian Service Identity controller
  • sweeper/ — pod-labelling controller
  • forge_containers/ — ForgeApp operator (Go)

Temporal workflow services¶

  • kitt-runbooks/ — SRE runbooks as Temporal workflows
  • scraper/ — Temporal-backed Python web scraper

Edge / sidecar services¶

  • iam-sidecar/ — GCP token sidecar
  • k8s-metadata-collector/ — pod/node metadata → Kinesis
  • go-app/ — sample Go service (Pub/Sub, GCS, Spanner)

Observability stack¶

  • logging/ — Fluent Bit → Elasticsearch ingest pipeline
  • monitoring/ — Prometheus + Grafana for Temporal/dtaske

Batch / GPU workloads¶

  • vocalno/ — Volcano batch scheduler
  • pae/ — Portable Async Engine (Kueue)
  • pae-apps/ — KueueViz dashboard + sample jobs

Cryptography & routing libs¶

  • portable-cryptor/ — AWS↔GCP KMS-portable encryption
  • routers/ — lightweight Python URL router

Lambda / serverless¶

  • lambda/ — AWS Lambda scrapers (DynamoDB + Postgres backends)

Reporting & analytics¶

  • atlassian_services/ — Atlassian microservice deployment inventory
  • cdp_services/ — service-to-environment explosion + region stats
  • costs-estimates/ — GCP/AWS pod-hosting cost calculator

Reference workloads & misc¶

  • cc/ — Confluence Cloud monolith manifests
  • forge/ — sample Atlassian Forge applications
  • kittz/ — multi-region EKS deployment orchestrator (Node.js)
  • busybox/ — debug container image
  • ai/ — critical-pod ResourceQuota
  • tests/ — service-discovery test fixtures

forge/ — sample Atlassian Forge applications¶

Purpose¶

Reference / development implementations of Atlassian Forge apps used to exercise the forge_containers/ — ForgeApp operator (Go) operator end-to-end.

Layout¶

forge/
  quiz-app/
    src/                       # quiz application code
  i18n-question-generator/
    src/frontend/              # frontend code
  long-running-app/
    src/generateReport.js      # async report generation
    src/pushToQueue.js         # job push to async queue

Tech¶

JavaScript / TypeScript, Node.js. Each subdir is an independent Forge-app project (own package.json / manifest).

Integration¶

When packaged as a ForgeApp CRD instance and applied to the cluster, these apps are reconciled by the forge_containers/ — ForgeApp operator (Go) controller, which generates the matching Deployment + ServiceAccount + sidecars.

Use case¶

  • quiz-app — minimal happy-path Forge app, used as a smoke test.

  • long-running-app — exercises the async / queueing path; pairs well with pae/ — Portable Async Engine (Kueue) workloads.

  • i18n-question-generator — exercises frontend rendering.

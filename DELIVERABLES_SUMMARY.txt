================================================================================
DESIGN HIGHLIGHTS
================================================================================

1. PURE SYNTAX VALIDATION (TIER 1)
   - No topology load needed
   - No LLM calls
   - No complex dependencies
   - Result: Lightning-fast feedback

2. AUTO-DISCOVERY
   - `glob("**/*.jinja2")` finds all templates
   - New templates auto-tested
   - No manual registry to maintain
   - Scales to 1000+ templates seamlessly

3. LAYERED CONFIDENCE
   - TIER 1: ✅ templates are syntactically valid
   - TIER 2: ✅ topology loads & inferencers wire correctly
   - TIER 3: ✅ end-to-end task execution works

4. DEVELOPER-FRIENDLY
   - Pre-commit hook runs automatically
   - Errors point to exact template & line
   - Clear actionable messages
   - <2 second feedback

5. CI-READY
   - Fast gate (TIER 1+2 < 90s) for every PR
   - Slow smoke test (TIER 3 ~10min) for main only
   - Clear distinction: gate vs comprehensive

  Pros: Catches some bugs

  Verdict: TIER 1 automates this completely

Our Solution: Layered preflight tests

mcp-atlassian-exp
=================

.. note::

   **Package type:** INTEGRATION (MCP)  |  **Python module:** ``mcp_atlassian_exp``

Experimental Model Context Protocol (MCP) server that exposes Atlassian Jira, Confluence and Bitbucket capabilities to LLM agents.

This documentation set is generated by the OpenStartup ``docs/`` Sphinx build.
It uses :mod:`sphinx.ext.autodoc` with locally-declared ``autodoc_mock_imports``
so that heavy third-party dependencies (Atlassian SDKs, MCP runtime, web
frameworks) do not need to be installed in the docs build environment.
